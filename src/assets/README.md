# src/assets 资产登记表

> 本目录承载 M3 混合渲染的**贴图层**（WebP）。程序化绘制物件（木桌/卦盘/竹筒/铜钱/沙漏沙流）**不在此处**，它们仍是代码画的。
>
> 铁律（《M3 美术接入规范》§2/§3）：
> - 单张位图 ≤ 200 KB；塔罗牌单张 ≤ 100 KB，分辨率 ≤ 512×768
> - WebP 总量 ≤ 2 MB（门禁② 聚合校验）
> - **每加一张图，必须同时在 `ci/art-whitelist.txt` 登记**，否则门禁② 拒收
> - 任何单张超 200 KB 的图片**不得入库**

## 目录约定

```
src/assets/
├── tarot/
│   ├── back.webp            # 卡背（主包，≤100KB，≤512×768）
│   ├── faces/
│   │   ├── core/            # 主包核心牌（必要几张）
│   │   └── ondemand/        # 按需加载（CDN，不进主包）
└── env/
    ├── felt-grain.webp      # 毛绒地毯质感（≤256×256，≤30KB，可选）
    └── window-view.webp     # 窗外风景（≤512×512，≤50KB，可选）
```
